Aplicação web desenvolvida para a empresa **Madeira e Cia Ltda.** com o objetivo de realizar o cálculo preciso de descontos em compras de acordo com a forma de pagamento escolhida pelo cliente.

---

## 🛠️ Correções e Implementações Realizadas

* **Correção das Regras de Negócio**: Ajuste dos percentuais de desconto para **Boleto Bancário (8%)** e **Depósito Bancário (10%)**.
* **Inclusão do Pix**: Implementado como opção de pagamento instantâneo mantendo o desconto de **10%**.
* **Formatação Monetária**: Exibição dos valores calculados no padrão brasileiro de moeda (`R$`).
* **Design Personalizado**: Interface em tons de vermelho com badges e identidade voltada à transparência e inclusão.
* **Documentação Lógica**: Inclusão de comentários reflexivos ao final dos arquivos sobre as etapas do raciocínio utilizado.

---

## 💻 Como Rodar o Projeto Localmente

1. Clone este repositório ou baixe os arquivos.
2. Mova a pasta para o diretório de seu servidor local (ex.: `C:\xampp\htdocs\`).
3. Inicie o servidor **Apache** no painel do XAMPP.
4. Acesse no seu navegador: `http://localhost/fichario_madeira/index.php`
